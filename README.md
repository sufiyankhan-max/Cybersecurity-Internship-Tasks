

# DevelopersHub Internship – Cybersecurity Tasks

This repository contains the complete work for the **DevelopersHub Corporation Cybersecurity Internship**.  
It covers tasks carried out to strengthen security measures for a web application, including assessment, implementation of security fixes, and final reporting.

---

## Internship Overview

During this internship, the following activities were performed:

- **Security Assessment:** Identification of vulnerabilities in a web application such as XSS, weak password storage, and misconfigurations.  
- **Implementing Security Measures:** Input validation, password hashing, token-based authentication, and securing HTTP headers.  
- **Advanced Security & Reporting:** Basic penetration testing, logging setup, security best practices checklist, and final report compilation.

---

## How to Access the Work

- **Final Report:** A detailed PDF (`Final_Report.pdf`) is included summarizing all tasks, findings, and fixes.  
- **Code:** All code and configurations used during the internship are included.
